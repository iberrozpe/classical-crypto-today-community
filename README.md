# Classical Crypto Today — community

Questions, discussion and feedback for [Classical Crypto Today](https://classicalcryptotoday.com), an educational site about the classical cryptography in use today and its move to post-quantum.

- **Ask a question:** open a discussion in [Q&A](../../discussions/categories/q-a).
- **Discuss a page:** use the discussion at the bottom of any Learn, Use Case or Standards page. Those threads live in the *Page discussions* category.
- **Report an error or suggest an improvement:** [open an issue](../../issues/new?labels=feedback).

New questions get a first answer from Claude, an AI model, written from the site's own pages and marked as AI. It can be wrong; people can correct or add to it. See [how it works](https://classicalcryptotoday.com/community).

Please keep it on topic, and don't post personal data, secrets or real keys. Everything here is public. The site's [Terms](https://classicalcryptotoday.com/terms) apply.

This repo holds no source code.
